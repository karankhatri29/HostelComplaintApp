# Complaint Management App (Frontend)

This is a **React Native (Expo)** project that provides a role-based complaint management system.  
The app supports **Students, Cleaners, Wardens, and Electricians** with different dashboards and functionalities.

---

## **Features**

### **Role-Based Dashboards**
- **Student Dashboard**
  - Create **New Complaints** (Room Cleaning, Electrician Repairs).
  - View **Pending Complaints** and **Complaint History** using tabs.

- **Cleaner Dashboard**
  - View all **Cleaning Requests**.
  - **View Details**, **Add Remarks**, and **End Requests**.

- **Warden Dashboard**
  - View all **Repair Requests** submitted by students.
  - **Ignore**, **Postpone**, or **Generate Repair Tokens** (for Electricians).

- **Electrician Dashboard**
  - View all **Repair Tokens** generated by the Warden.
  - **View Details**, **Add Remarks**, and **End Requests**.

---

## **Tech Stack**
- **React Native (Expo)** – Cross-platform development for Android, iOS, and Web.
- **React Navigation** – Stack and Tab navigation.
- **React Native Paper** – Prebuilt UI components for a clean and modern interface.
- **React Hook Form + Yup** – For form handling and validation.
- **TypeScript** – Type-safe and maintainable code.

## **Installation**

### **1. Clone the Repository**
```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
```
### **2. Install Dependencies
  npm install
### **3. Start the App
  npm start
Press a to run on Android Emulator.
Press w to open in the web browser.
Scan the QR code with the Expo Go app to run on your mobile device.
